# Java Programs

Welcome to my Java Programs repository!

This repository contains a collection of beginner-friendly Java programs created as part of my programming practice and learning journey.

## Programs Included

1. Palindrome.java – Checks whether a given input is a palindrome.
2. Students_details.java – Demonstrates student details using Java.
3. char_diamond.java – Prints a diamond pattern using characters.
4. gradeCalculation_method.java – Calculates grades using Java methods.
5. numbers_pyramid.java – Prints a pyramid pattern using numbers.

## Technologies Used

- Java
- Conditional Statements
- Loops
- Methods
- Basic Programming Concepts

## How to Run

1. Clone this repository.
2. Open the Java file in VS Code or any Java IDE.
3. Compile the program using javac.
4. Run the program using the Java command.
